Fullstack Developer Test Assignment

Problem Statement

Implement a URL shortening service.

⸻

Requirements

* Use Java & Spring for the backend.
* Preferably use Angular for the frontend.
* The backend should be highly available and survive data center outages.
* The system should be scalable:
    * When a short link becomes popular, it may receive a sudden spike in read requests.
    * These spikes should not impact the responsiveness of the application.
* A user should be able to:
    * View their own shortened links.
    * Deactivate existing links.
    * View usage statistics for their links.

⸻

Implementation Notes

* You are not required to deliver a fully working solution.
* It is up to you how much time you spend on the assignment.
* The reviewers are interested in your thinking process, not just the final implementation.

Prepare a presentation for the next interview:

* Approximately 15–20 minutes long (around 15 slides).
* Be prepared to answer questions during the presentation.
* The overall interview session will be approximately 60 minutes.

⸻

Suggested Presentation Structure

Your presentation may include:

* Overall system architecture (cloud-specific architectures such as AWS or Kubernetes are preferred).
* Frontend architecture.
* Security:
    * Data in transit.
    * Data at rest.
* Authentication and user management.
* CI/CD pipeline design.
* API design (for example, OpenAPI specification fragments).
* Suggested Spring technologies used.
* Approach for efficiently building and maintaining the frontend.
* Relevant code fragments (backend and frontend).
* Metrics, monitoring, and alerting technologies.
